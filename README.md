# Tanghe Inverted Siphon Autonomous Operation System

## Project Structure
- `src/simulation`: Physical modeling (Hydraulics, Dynamics, Sensors, Actuators).
- `src/control`: Intelligent control algorithms (Spectral-MPC, Local Active Damping).
- `src/web`: Web interface for visualization and interaction.

## Coding Conventions
- Use Python 3.
- Follow PEP 8 style.
- Use docstrings for all classes and functions.
